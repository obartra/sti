sti.care API

This is the blind backend for sti.care. It stores only encrypted blobs and opaque routing tokens, so it can’t read your status, your diagnoses, or who you’re connected to. The keys that decrypt anything never reach it.

Nothing here is meant to be browsed. The app talks to it; you don’t need to.
